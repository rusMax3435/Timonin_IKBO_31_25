# Dependency Graph Visualizer

Инструмент визуализации графа зависимостей для менеджера пакетов.
Выполнен в рамках дисциплины "Конфигурационное управление" (Вариант №26).

## Текущий этап: Этап 1. Минимальный прототип с конфигурацией

### Общее описание
На данном этапе реализовано CLI-приложение на Python, которое принимает 
параметры через опции командной строки, валидирует их и выводит 
в формате ключ-значение.

### Доступные опции командной строки
- `-p`, `--package` (обязательный) — Имя анализируемого пакета.
- `-r`, `--repo` (обязательный) — URL-адрес репозитория или путь к файлу.
- `-t`, `--test-mode` (флаг) — Включает режим тестирования (проверка пути).
- `-v`, `--version` — Версия пакета (по умолчанию `latest`).
- `-o`, `--output` (обязательный) — Имя файла для сохранения графа.

Проект использует только стандартную библиотеку Python (3.8+).
